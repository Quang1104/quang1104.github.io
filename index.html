How the workspace works +

Members submit annotation output by job and track their own tasks. Reviewers return tracks with issue notes, recheck corrections, and mark completed work. Admins assign jobs, configure daily KPI, manage attendance, and review weekly progress.

Inside the experiment +

The question

How can a Vietnamese chatbot generate more reliable SQL over a cryptocurrency database?

My contribution

I owned the RAG / SQL-generation layer and designed four agents: Coordinator, Query Classifier, SQL Generator, and Data Analyst. My teammate built the streaming and ETL pipeline.

The comparison

We compared baseline Text-to-SQL RAG, self-reflective RAG with execution feedback, and Hybrid SQL Cards combining BM25 with semantic retrieval.

The result

Hybrid SQL Cards reached 91% execution accuracy and 88% result accuracy, versus 80% and 75% for baseline retrieval. Average retries decreased from 1.45 to 0.52 per query.

Graduation thesis · Oct 2025 – Feb 2026 · These results describe the thesis test set.

CDC DIABETES HEALTH INDICATORS / TEAM OF 6

A retrospective statistical learning project starting from 253,680 BRFSS 2015 survey records. The target combines prediabetes and diabetes into one class, compared with no diabetes.

My contribution

I led data preprocessing, including removing 23,899 duplicate records and handling class imbalance.

Study design

After preprocessing, the team used a 70/30 split: 112,944 training rows and 48,372 test rows. Only the training set was oversampled, bringing the minority class to half the majority-class size.
