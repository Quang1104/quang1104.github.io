Project notes

How Klang works.

I built Klang to explore what should happen after you say a command out loud.

Voice you can see
The full app has push-to-talk and Vietnamese narration. A canvas orb changes colour with the assistant’s state and responds to audio levels.
A command becomes an action
Known commands can start a timer or open a briefing directly. A server-side skills layer validates actions before they run.
AI with a fallback
Open-ended requests go to an LLM. The server can fall back to another configured provider before the reply starts. This browser demo uses scripted responses.
