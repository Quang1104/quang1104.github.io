Klang.

Klang is a Vietnamese-first personal assistant. It brings weather and news into one briefing, helps you start a focus session with music, and answers open questions through chat. The full app also supports connected Gmail and a personal sleep journal.

Vietnamese transcript

Xin chào, mình là Klang. Mình có thể đọc bản tin, xem thời tiết và giúp bạn vào guồng tập trung. Bạn có thể nói bật nhạc piano, bắt đầu tập trung, hoặc hỏi mình về một chủ đề bạn đang tìm hiểu. Trong bản dùng thử, hãy bấm nút mic và nói bật nhạc. Bạn cũng có thể nghe thử một đoạn bản tin.

Project notes

How Klang works.

I built Klang to explore what should happen after you say a command out loud.

Voice you can see
The full app uses push-to-talk and Vietnamese narration. Its particle orb shows when Klang is listening, thinking, or speaking. Try a spoken Vietnamese command or hear a recorded sample in the demo.
Daily briefings and shortcuts
Klang can read scheduled briefings and include weather. Common requests can open a tool or start a focus timer directly. A skills layer checks that an action is allowed before it runs.
AI with a fallback
The full assistant streams answers and can switch AI providers before a reply starts. The development build adds passphrase-protected web chat through a Cloudflare Worker. This public demo uses fixed commands and sample content.
